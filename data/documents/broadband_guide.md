# Broadband Guide -- TeleConnect India

## Getting Connected: The Installation Process

Once you have placed a broadband order with TeleConnect India (online or at a store), a technician will visit your premises to complete the installation.

**What to expect:**
- **Technician visit within 3 working days** of order confirmation
- The visit takes approximately 1.5 to 2 hours
- **You must be present** (or a responsible adult must be at home) for the duration of the visit -- the technician cannot install without someone present to provide access and sign the installation completion form

On the day of installation, the technician will:
1. Run fibre cable from the nearest junction point to your premises
2. Install the ONU (Optical Network Unit) modem -- this is TeleConnect's equipment, provided free with any broadband plan
3. Test the connection speed and signal quality
4. Hand over the connection details (login credentials if required)

---

## Equipment

**ONU Modem (provided free):** The ONU modem converts the fibre signal into an ethernet connection. It is TeleConnect's property and must be returned if you cancel your connection. Do not attempt to open or modify the ONU -- this voids your connection agreement.

**Wi-Fi Router (your responsibility):** The ONU provides an ethernet port, not Wi-Fi. To get wireless internet throughout your home, you need a Wi-Fi router:
- **Option 1:** Use your own router (connect it to the ONU via an ethernet cable)
- **Option 2:** Purchase a TeleConnect 5G WiFi Router, which is compatible with all TeleConnect broadband plans and supports Wi-Fi 6 for faster in-home speeds

If you purchase a TeleConnect router, it can be set up by the technician during installation.

## Basic Setup Steps

After the technician's visit, if you need to set up or reconfigure your router:

1. Connect the ONU modem to the wall port (the fibre socket the technician installed)
2. Connect your Wi-Fi router to the ONU using an ethernet cable (LAN port on ONU to WAN/Internet port on router)
3. Power on the ONU -- wait 2 minutes for it to fully initialise
4. Power on the router
5. Open your router's admin panel (typically 192.168.1.1 in a browser) to set your Wi-Fi name (SSID) and password

If your plan requires PPPoE authentication, the technician will provide the username and password during installation.

## Basic Troubleshooting

**No internet connectivity:**
1. Check that all cables are firmly connected (ONU to wall port, router to ONU)
2. Check the ONU power light -- it should be solid green. If it is red or blinking, restart the ONU by unplugging and replugging the power cable, then wait 3 minutes
3. Check the router power light -- it should be solid. Restart the router if needed
4. Try connecting a laptop directly to the ONU via ethernet (bypassing the router) -- if this works, the issue is with your router
5. If none of the above resolves the issue, call TeleConnect support at 198

**Slow speeds:**
1. Run a speed test at fast.com while connected via ethernet (wired) -- this gives the most accurate reading unaffected by Wi-Fi interference
2. If wired speed is close to your plan speed, the issue is Wi-Fi coverage -- try moving closer to the router or upgrading to a mesh Wi-Fi system
3. If wired speed is significantly below your plan speed, call 198 to report a line fault

**Intermittent connectivity:**
Report to 198. Intermittent issues often indicate a fibre line fault or ONU hardware issue and require a technician visit.

## What "Unlimited Data" Means

All TeleConnect broadband plans are unlimited -- there is no monthly data cap. You can download and upload as much as you need without hitting a hard limit.

**Fair usage policy on broadband:** During periods of significant network congestion (typically evening peak hours in dense areas), TeleConnect may manage speeds of very high-volume users to maintain quality for others. This is not a fixed cap -- it applies only during congestion events and your speed returns to normal when congestion eases.
